Master rules (excerpt from plan)

  • P1 · Hero = route + price. Never decorative ship art. 3-second recognition test.
  • P2 · One component <QuoteCard>, three viewers. No forks. Molecule layer takes vis/cta derived data, not role.
  • P3 · Field visibility via quoteCardVis(viewer, field) — same 4-layer pattern as v3.2 Registry.
  • P5 · One highlight color per card (by status). No rainbow tag walls.
  • P6 · Capability tags = only what the supplier HAS. Never grey-out absent caps. Max 5 visible + +N.
  • P7 · Customer surface: cost / margin / supplier_id / real supplier name / internal notes always redacted. Supplier name = "Sanlyn Ocean" or "Verified · COSCO".
  • P8 · Cross-category. Swap <RouteDiagram mode> + <PriceBlock units> to render truck / customs / insurance / DDP from the same skeleton.
  • States · DRAFT · NEEDS_REVIEW · AVAILABLE · TARGET_PRICE · QUOTING · BOOKED · EXPIRED · HIDDEN · INTERNAL_ONLY.
  • CTA cap · Max 3 visible buttons + ⋯ overflow. Max 1 filled primary per card.
  • Mobile fold · Hero 140→96px, prices 3→2 col, caps 5→3+N, meta collapse, CTA → primary + ⋯. Never hide: status / quote_id / 20GP price / primary CTA.
