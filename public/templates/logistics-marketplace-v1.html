📝 Design notes — please confirm before React implementation

  • Replaces: existing Step 1 (Choose Route + Recent + Continue button). Step 2 picker still works — clicking 📅 Book CTA jumps user into the existing Step 2 flow with carrier/voyage pre-filled.
  • Dedupe rule: when multiple forwarders quote the same carrier + voyage, only the cheapest row is shown. Other forwarders are silent (loser, no UI). Confirmed: "只看价".
  • Customer CTAs: Book now (accept current best price) and Adjust target (open Set-Target modal, posts to 抢单池 for forwarders to bid lower). 立即抢单 from 图3 is the FORWARDER-side button — not shown on this customer view.
  • Region filter: tabs across the top filter routes by destination region. Counts auto-update.
  • BEST flag: golden ★ on the carrier whose price ≤ customer target OR is the absolute cheapest on the route.
  • BOOKED flag: green chip on carriers Sanlyn has already locked space with (vs. just published rates).
  • Data sources: freight_rates.raw.sharing (marketplace-shared rates) + shipping_plans (next 3 sailings per lane) + the customer's last quote/target as "Your target".
  • Empty state: dashed "+ Add Custom Route" tile invites custom-route inquiry → posts to bid pool when no published rate exists.
  • Trust banner (top): kept exactly as in current Logistics Hub — pure advert, zero API.
  • Removed: Sourcing NEW button (代购) — duplicate of product-page ordering.
