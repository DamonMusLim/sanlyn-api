🏭 Brand Routes · 公版 SaaS 模板

每行 = 一条规则：工厂(部门) + 品牌 → 客户列表(多选)。所有数据按 tenant_id 隔离，从 API 实时加载。
🏢 租户： 从 JWT.tenant_id 解析   |   当前用户角色：admin
公版 SaaS · 无硬编码 · fail-closed
💡 每条规则必须显式：工厂 + 品牌 + 客户。工厂有权选择不授权某客户。
❌ 没有「默认走某主体 = 所有客户都可」的兜底 — 数据库无此 (工厂, 品牌, 客户) 三元组 = 客户在产品页看不到。
GET /api/db/factories?tenant_id=X → 加载本租户的工厂 + 部门
GET /api/db/distinct?col=brand&tenant_id=X → 加载本租户的所有品牌
GET /api/db/customers?role=buyer&tenant_id=X → 加载本租户的所有买家
GET /api/db/customer-brand-routes?tenant_id=X → 加载现有规则
POST /api/db/customer-brand-routes → 保存/更新规则（强制带 tenant_id）
共 0 条规则 · 0 客户授权 · 0 NDA
