📐 Design rules

  1. Sticky chip filter on top — All / Order / Shipping / Customs / Inspection. Tap to scroll/jump. Disabled chips (no docs yet) dim to 40% opacity.
  2. Phase-aware default expand:
    • pending / confirmed → only ORDER expanded
    • producing → ORDER collapsed, INSPECTION (QC) expanded
    • shipping_booked / in_transit → SHIPPING expanded
    • arrived / customs → CUSTOMS expanded
    • delivered → all collapsed (read-only summary)
  3. "Coming up" stub — when a section has no docs yet, show 1 collapsed row with count instead of N "Not yet available" rows. Remind buttons hide too (no factory to remind on doc that doesn't exist yet).
  4. Generated docs always available — Order section always renders on the strength of having SC/IV/PL auto-generated.
  5. Section header click = expand/collapse — caret ▾ open / ▸ closed. State remembered while panel open.
  6. No drilling — everything is at most 2 taps: open detail panel → tap section / chip → see doc. No nested modals.
