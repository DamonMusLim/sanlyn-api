🔐 权限链 · 谁能看到什么

下单页看到哪些工厂（买家视角）

买家 = ENRICH (CN-00040) ↓ SELECT company_code_b FROM partner_relationships WHERE company_code_a = 'CN-00040' AND relationship_type = 'customer_factory' ↓ [petbaby] ← 这个买家只能选 1 个工厂 ↓ hydrate from factories + seller_profiles (petbaby 在这里) ↓ 下单页 dropdown 显示: "厦门巴匕进出口有限公司"

下单页看到哪些产品（买家 ∩ 工厂）

products WHERE brand ∈ customer_brand_authorizations (WHERE customer_code = 当前买家) AND brand ∈ factory_brand_authorizations (WHERE factory_code = 选中工厂) ↓ 交集 = 客户授权 + 工厂能管 — 全部满足才显示

工厂登录后看到哪些订单

工厂 = 中宠 (zc-oem) ↓ 看自己管的品牌: factory_brand_authorizations WHERE factory_code='zc-oem' → [WANPY, TRULY, SNIFFLY, ...] ↓ 查这些品牌的订单: orders → products → brand ∈ 上面列表 ↓ 显示订单，但客户名脱敏成 "Sanlyn Customer #001"

外贸 vs 工贸一体 — 谁定价

factories.portal_type = ? ├ 'integrated' (工贸一体: 福新 FX, 泰迪 td) → 工厂自填 factory_price └ 'foreign_trade' (外贸代出口: 中宠 zc-oem, 宠爱 CL) → 巴匕/洋宝宝填外贸价 (已含代理费)

派生关系查询（admin 调试用）

-- 某工厂的全量下游买家 SELECT c.name_en, pr.granted_at FROM partner_relationships pr JOIN customers c ON c.company_code = pr.company_code_a WHERE pr.company_code_b = 'zc-oem' AND pr.relationship_type = 'customer_factory'; -- 某工厂的全量上游货代 SELECT c.name_en FROM partner_relationships pr LEFT JOIN customers c ON c.company_code = pr.company_code_b WHERE pr.company_code_a = 'FX' AND pr.relationship_type = 'factory_forwarder'; -- 某工厂的全量品牌（产出能力） SELECT DISTINCT brand FROM products WHERE factory_code = 'zc-oem';
