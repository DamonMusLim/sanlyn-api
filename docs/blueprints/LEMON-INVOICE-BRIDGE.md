# 🍋 开票衔接柠檬云流程 蓝图（feature/lemon-invoice-bridge）

日期: 2026-07-18

## 一句话
我方确认页产出「开票要素」→ 桥送进柠檬云「云发票·立即开票」自动填 → **人工点发票开具** → OCR回读核对 → 回填我方+柠檬云自动发邮件。

## 现状（本session实测/Damon截图确认）

### 我方已有（本session建）
- 港杂开票确认页（`invoice-collab-section`）产出开票要素：购买方名称+税号 / 品目`*经纪代理服务*港杂费` / 税率`1%`(小规模) / 金额 / 备注(收款账号按币种+提单号·柜量) / 财务邮箱。
- 落 `invoice_collab_confirm_overrides` 草稿；我方代开/对方自开 toggle；月结合并端点。

### 柠檬云侧（Damon 2026-07-18 截图 + 实测）
- 真开票=柠檬云**「云发票」独立应用**：开票管理→立即开票→**发票开具**（蓝按钮=扣扳机）。
- ⚠️跟云财务(jpro6/jproapi)**两套系统** → 之前逆向的1027接口**没有开票**。
- 🔴当前开不了：**税局登录=未登录、认证=未认证、可用额度¥0.00**。
- 港杂费要先在「项目信息」建`*经纪代理服务*港杂费`(简易计税1%)。
- ✅交付信息支持**最多3邮箱**(`;`隔开)→ 柠檬云**自动发邮件**，我方不用写发邮件段。
- 会话=Electron `persist:lemon`(meituan-merchant)，[[reference_lemon_session_via_electron]]。
- 销售方税号核对一致：柠檬云`91310106MAE9L4AQ28`==companies.OCEANBABY。

## 🔴 三个前置阻塞（要Damon/环境，桥建好也开不了票）
1. **税局登录+认证**：实名/短信，Damon操作，红线AI不碰。
2. **港杂费项目建档**：柠檬云项目信息新增(简易计税1%)，否则报"0%/免税/简易计税请先新增对应项目"。
3. **云发票开票接口/表单未逆向**：需Damon走一遍开票，`:3799/lemon-record`抓真实请求 → 才能自动填。

## 铁律
- **开票=对外不可逆动作，每张必须Damon人工点「发票开具」**。桥只做到「自动填好」，扣扳机永远人点。
- 销售方主体决定票种/税率：洋宝宝=小规模只能普票+征收率1%/3%；巴匕=一般纳税人。系统按销售方company纳税人类型限定。
- 开票要素从公司表唯一真源带出，人不重敲。

## 分阶段

### P0 · 我方开票就绪（纯我方后端，本分支先做）
- 确认页状态机加「待开票」：草稿confirmed → 生成`invoice_ready`标准结构(买卖方/品目/税率/金额/备注/邮箱/币种/票种)。
- 校验开票就绪：买方税号必填、财务邮箱必填、金额>0、销售方纳税人类型定票种税率。
- 缺项红标挂起，不放行。**不碰柠檬云**。

### P1 · 逆向柠檬云开票（需Damon配合走一遍）
- Damon在Electron柠檬云tab登录(过滑块)+税局认证 → 走一遍真开票 → `:3799/lemon-record`抓「发票开具」的真实请求(host/接口/参数) 或 DOM结构。
- 定位云发票开票host(数电票子应用，非jproapi)。

### P2 · 桥（草稿→自动填柠檬云）
- CLI/service：取`invoice_ready` → 复用Electron persist:lemon会话 → 自动填立即开票表单(种类/购买方/项目/税率/金额/备注/交付邮箱)。
- **停在填好，弹给Damon点「发票开具」**。

### P3 · 回读闭环
- 开出后：柠檬云自动发邮件(交付3邮箱)；OCR回读数电票逐字段vs草稿(复用ocr-verify)，不符红标不算完；回填`invoice_no`/PDF到`finance_invoices_out`+确认页状态→已开票→收款对上→reconciled。

## 本分支先做什么
**P0（纯我方，不依赖柠檬云）**：确认页「待开票」状态机 + `invoice_ready`标准输出 + 就绪校验。这段现在就能建、能验，不卡柠檬云前置。

P1需要Damon：①柠檬云税局登录认证 ②建港杂费项目 ③走一遍开票让我录制。三个齐了才能建桥(P2)。
