# TASK-HALL-DAILY-ENTRY-RULES-001
## Sanlyn OS · 任务大厅每日入口规则设计

**日期**: 2026-05-11  
**目标**: 定义 Damon 每天打开任务大厅时应该看到什么、怎么看  
**当前状态**: 设计文档，未实现

---

## 1. 设计原则

**核心问题**：任务大厅现在98条平铺，打开第一眼看不出"今天要做什么"。

**解决方向**：不是让 Damon 扫描98条，而是让系统**主动告诉 Damon 今天3件事**。

---

### 2.2 优先级分组（排序规则）

| 优先级 | Group 名称 | 筛选条件 | 显示方式 |
|--------|-----------|---------|---------|
| 1 | ⚡ 今日必须处理 | risk_level=high OR (逾期>7天 AND task_type != payment_term_confirm) | 展开，置顶 |
| 2 | 🔴 高风险逾期 | risk_level=high AND status=open | 展开 |
| 3 | 🟡 真实运营阻塞 | task_type IN (交期确认,装货安排,资料补齐) AND status=open | 展开 |
| 4 | 🔵 等 Damon 决策 | 分类为 NOISE_CANDIDATE 且 requires_damon_decision=TRUE | 折叠，1行摘要 |
| 5 | 📦 批量噪音候选 | task_type=payment_term_confirm AND id LIKE 't-pt-%' | 折叠，仅显示计数 |
| 6 | ✅ 已完成 / 已归档 | status=done | 折叠，可展开查看 |

## 3. 每日提醒机制设计

### 3.1 当前状态
- **无定时任务** — tasks 表有数据，但没有任何 cron/scheduler 生成每日摘要
- **无 push 通知** — assignee_user_id 全 NULL，没有人收到通知

### 3.2 最小可行提醒方案

**方案A（推荐·成本最低）**：Claude 每日手动运行
```
每天 Damon 开始工作时，说："Claude，查一下任务大厅今天有什么"
Claude 执行 DB query → 按优先级生成摘要 → 推送微信（/Users/mac/bin/wechat-push）
```

**方案B（半自动）**：scheduled-tasks 配置每日9点 fire，Claude 执行 query+push

**方案C（完整自动化）**：
1. 在 `api/tasks-daily-summary.js` 添加 GET 接口
2. 配置 cron job 每日9点调用
3. 结果推送企业微信 webhook

### 3.3 微信推送格式（wechat-push 可用版）

```bash
/Users/mac/bin/wechat-push "📋 任务大厅 2026-05-11
⚡ 高风险 1条: 38-XM-251 交期确认 (逾期18天)
🟡 中风险 2条: 38-XM-246 备货照片 / 37-XM-243 司机
📦 噪音候选 95条等待归档批准"
```

## 4. 每日任务大厅 SOP（Damon 操作手册）

```
每日9:00（或开始工作时）：
Step 1. 看横幅摘要 → 今天有几条真实任务？
Step 2. 处理 Group 1（⚡今日必须处理）中的高风险任务
Step 3. 处理 Group 3（🟡真实运营任务）
Step 4. 如果批量噪音 Group 显示"等待批准"，决定是否批准归档
Step 5. 在微信或 Claude 对话中说出批准语

不需要每天做的事：
✗ 不需要逐条看 payment_term_confirm（折叠了）
✗ 不需要关注 Done 列表（已完成，历史记录）
✗ 不需要手动排序（系统自动按优先级排）
```
